# 管理员简历展示设计

## 目标

为管理员端提供用户简历列表和详情展示，使管理员能筛选简历、下载原 PDF，并查看 PDF 原始文本、AI 结构化解析和 AI 分析结果。

## 交互

- 侧栏新增“简历管理”，进入分页列表。
- 列表支持姓名/邮箱关键词与解析状态筛选，展示用户、文件名、岗位、状态和上传时间。
- 详情采用独立路由和 A 方案标签页：顶部展示简历与用户摘要；正文在“PDF 原始文本”“AI 结构化解析”“AI 分析”间切换。
- 下载使用已登录管理员的 axios 实例请求 Blob，再以浏览器临时对象 URL 保存文件，不暴露管理员 token 到 URL。

## API 映射

- `GET /resumes` -> 列表。
- `GET /resumes/{id}` -> 详情。
- `GET /resumes/{id}/download` -> PDF Blob。

## 状态

列表、详情均展示加载和空状态；历史简历的 `extracted_text` 为空时在原始文本标签页显示“暂无 PDF 原始解析文本”。AI 字段为空或无法显示时使用相应空状态。
